# L8. Git workflow va birinchi sprintni rejalashtirish — o‘qituvchi namunasi

**Bu sun’iy to‘ldirilgan misol. Jamoaning haqiqiy bajargan ishlari, mavjud PRlari yoki servis akkauntlariga dalil emas. A/B/C/D anonim o‘quv rollari. Talaba bu matnni o‘z natijasi sifatida ko‘chirmaydi.**

## Sprint 1 — reja namunasi
L8–L10 oralig‘i. Goal: talaba UniGuide’da olti maqolani ko‘rib, turkum bo‘yicha ajrata olsin. Tanlov: US01=3, US02=3, US03=2; jami8SP. Pointlar nisbiy murakkablik, soat emas. Jamoa 4 a’zo, har biri 2soatlik darsdan tashqari vaqt ajratishini kelishadi; bu pointga avtomatik aylantirilmaydi.
A—kontentni tasdiqlash; D—ro‘yxat va kichik ekran; C—turkum API; B—test va PRlarni kuzatish. Ish branchi namunasi `lab08/category-filter`. Bitta kichik o‘zgarish, tekshiruv va teammate reviewdan keyin main’ga merge qilinadi.
Dalil zanjiri reja: US02 → GitHub issue → branch → commit → PR → review → test → main. Bu faylda haqiqiy PR/commit uydirilmagan; jamoa o‘z havolalarini yozadi. Tayyor referens ilova barcha funksiyaga ega; talabalar o‘z kontenti va kelishilgan kichik yaxshilashlarini boshqaradi, mavjud funksiyani "biz endi yozdik" deb ko‘rsatmaydi.
Jira: o‘z o‘quv loyihasida Sprint1 ochib maqsad va storylar kiritiladi; bepul imkoniyat yetarli bo‘lishi kerak, karta to‘lovi talab qilinmaydi. Ruxsat bo‘lmasa GitHub Projectsda reja yuritiladi va Jira amaliyoti tekshirilmagan deb yoziladi.

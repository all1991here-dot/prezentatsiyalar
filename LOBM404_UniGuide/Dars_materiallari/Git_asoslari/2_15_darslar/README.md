## Qanday foydalanamiz?

1. Darsni boshidagi oddiy savoldan boshlang; talabaga javob berish uchun vaqt bering.
2. Har bir buyruqdan oldin uning maqsadini ayting, keyin birga bajaring.
3. Rasm va natijani taqqoslang. Fayl, branch va hisob nomlarini o‘z mashqingizga moslang.
4. Yakunda mustaqil mashq va qisqa savollar orqali tushunganini tekshiring.

Mashqlar oddiy matn fayllari bilan bajariladi; Java o‘rnatish talab qilinmaydi. Ayrim rasmlarda boshqa nomlar uchrasa ham, Git qoidasi bir xil. Faylni o‘chirish, restore va reset kabi amallarda saqlanishi kerak bo‘lgan ishni oldindan ajrating. Sayt menyulari hisob turi va yangilanishga qarab farqlanishi mumkin.

Mahalliy Git buyruqlari va masofaviy almashishning asosiy jarayonlari alohida sinov repozitoriylarida tekshirildi. GitHub hisobiga kirish va uning yozish ruxsati har bir foydalanuvchining o‘z hisobida tekshiriladi.

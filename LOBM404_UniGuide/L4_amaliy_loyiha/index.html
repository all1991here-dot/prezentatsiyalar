Jamoaning harakati

Kuzatuv va xulosa

Hisob qoidasi: umumiy WIP = In Progress + Review. Bloklangan karta ham hisobda. To Do va Done kirmaydi.
Limitlar: In Progress ≤ 3; Review ≤ 2. Bu ssenariyning boshlang‘ich me’yori; barcha jamoalar uchun universal qoida emas.

O‘zingiz sinab ko‘ring

Joriy bosqichda kartani bir qadam oldinga o‘tkazishni tekshiring. Bu mashq ssenariyni o‘zgartirmaydi. Donega o‘tkazish uchun tekshiruv tasdig‘i talab etiladi.

Natijalar va rollar oldindan yozilgan namunalar. Tugmalar GitHub kartalarini o‘zgartirmaydi va serverga ma’lumot yubormaydi. Qayta ochilganda mashq 1-bosqichdan boshlanadi. Haqiqiy loyiha uchun README ko‘rsatmasi va o‘z doskangizdan foydalaning.

# Talaba shablonlari

L01–L15 fayllarini o‘z repozitoriyingizdagi `team/` papkasiga ko‘chirib to‘ldiring. `examples/` alohida o‘qituvchi namunalari; ular talaba dalili hisoblanmaydi. Har dars oxirida jamoa fayli, dalillar, tekshiruvchi va keyingi qadamni qayd eting. Maxfiy token, parol va haqiqiy shaxsiy ma’lumotni yuklamang.

Windows PowerShellda: `New-Item -ItemType Directory -Force team` va `Copy-Item templates/L*.md team/`.

macOS/Linuxda: `mkdir -p team` va `cp templates/L*.md team/`.

GitHub veb interfeysida ham faylni ochib matnini nusxalang; `Add file → Create new file` orqali `team/L01_charter.md` kabi yo‘l yarating. Darsdagi fayl nomlari bilan moslikni saqlang.
